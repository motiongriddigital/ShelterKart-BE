## What the rate limits are, so the user page can describe them

| Limit | Where | Counted as |
| --- | --- | --- |
| One code per address per 60 seconds | `request-code` | `cooldown` |
| Five codes per address per hour | `request-code` | `rate_limited_email` |
| Twenty requests per IP per hour | `request-code` limiter | `ip_rate_limited` |
| Thirty verifications per IP per hour | `verify-code` limiter | `ip_rate_limited` |
| Five wrong tries per code | `verify-code` | `code_wrong`, then `code_locked` |

All are shown per user on the user page (`signIn.last24h`, `last7d`, `last30d`) and across everyone on `GET /api/admin/auth/summary`.
